Source files: . Every List price comes from the R2.xls; it has no discount-tier data, so this tool only supports a manual % / multiplier override per line, not preset tiers. The price list is a flat 4-column sheet (Item Number, UPC, Description, List USD) with no section/category field, so Lookup is search-only. Part numbers with option suffixes (e.g. finish, LED color, keyed-alike) are priced individually in the source file even when the catalog PDF only shows the base model with an options table — search the exact suffixed part number here rather than assuming the base model's price applies. 8 items are the exception: the CX-DA800 and CX-DA810 door-alarm series aren't in the R2.xls at all — their List prices are pulled from the R6 PDF (p.34–35) instead and marked with a "Price from R6 PDF — not in R2.xls" badge wherever they appear.
